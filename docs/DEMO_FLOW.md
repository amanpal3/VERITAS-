# Demo Flow and Hackathon Presentation Script - VERITAS

1. **Problem Intro (1 min)**: Crime data is siloed; human analysts miss cross-case links.
2. **Dashboard Overview (1 min)**: System overview, summary statistics, top high-risk flags.
3. **Data Ingestion and AI Pipeline (1.5 min)**: Feed synthetic FIR and CDR; show real-time NER and entity resolution.
4. **Network Graph and Influencer Detection (2.5 min)**: Cytoscape visual graph, centrality analysis revealing hidden kingpin.
5. **Shortest Path and Community Detection (1.5 min)**: Trace money trail between two disconnected frontmen; show gang clusters.
6. **Q and A Wrap-up (0.5 min)**: Future roadmap and production readiness.
